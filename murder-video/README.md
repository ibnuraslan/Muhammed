# Case Files: AI true-crime shorts in the low-poly "PS2" style

This makes vertical 9:16 short videos (TikTok, Reels, Shorts) that look like an early-2000s video game:

- low-poly faceted characters with blocky "crumpled box" hair
- flat-shaded rooms rendered at low resolution and then upscaled
- chunky pixel-font captions with a thick black outline
- quick cuts, a handle watermark, and an end card

Everything is generated by code. Voices come from Piper TTS (offline and free). The music and sound effects are synthesised in Python. The 3D runs in three.js inside headless Chromium. ffmpeg assembles the final file.

## Make a video

```bash
./make.sh crippen            # -> build/crippen/crippen.mp4
./make.sh crippen --stills   # fast preview: one JPG per shot in build/crippen/stills/
node tools/render.js crippen --from 30 --to 40   # render only a section (seconds)
```

You need Python 3, Node 18+, ffmpeg and Playwright's Chromium. `make.sh` installs three.js and Piper and downloads the voices (about 370 MB) the first time it runs.

## Make a new episode

Copy `stories/crippen.json` and edit it. Each shot has these fields:

| field | meaning |
|---|---|
| `set` | `street`, `parlour`, `cellar`, `deck`, `deck_dawn`, `radio` (`variant: "dark"` for street/cellar) |
| `actors` | `{id, pos:[x,z], face:deg, anim, look}` or `{id, walk:{from,to,t0,t1}}` |
| `anim` | `idle nod nervous sit sit_shocked shocked sad admire kneel_dig kneel_shocked binoculars hold_paper type walk`. It can also be a list of `{at: 0..1, anim}` keyframes. |
| `cam` | `{from, to, look, lookTo}` for a moving camera, or `{focus: actorId, dist:[start,end], yaw, dy}` for a close-up push-in |
| `lines` | `{who, text, say?}`. `text` is the caption and `say` is the pronunciation sent to TTS. `who` must exist in `voices`. Shot length follows the speech automatically. |
| `stamp` | typewriter location/date box, e.g. `"LONDON\n1910"` |
| `sfx` | beds: `wind rain clock drip brick waves steps hum morse`; one-shots: `{name: teacup/whoosh/sparkle/sting/horn/bell, at: seconds}` |
| `music` | `calm`, `tense`, `drop`, `end` |
| `fx` | `fadein`, `flash`, `fadeout` |

Characters are defined in `cast`: skin, hair, hairStyle (`short bob bun updo balding tucked`), jacket, dress, glasses, moustache, beard, hat (`bowler cap captain`), height, width and so on. For new locations, add a builder to `engine/sets.js`.

Remember that the frame is narrow: keep the people in a shot within about 1 m of each other, or place the camera further back.

## Files

- `stories/*.json`: the scripts (story, cast, shots)
- `tools/build_audio.py`: TTS, the timeline (shot timing, captions, lip-sync envelopes), music, sfx and the mix
- `tools/render.js`: headless renderer that pipes frames to ffmpeg and muxes the audio
- `engine/`: three.js scene code (`textures.js`, `characters.js`, `sets.js`, `main.js`)
