# NeverBathed_v001 (B31): Phase 1 (P1)

The man who refused to bathe for 60 years. Generic characters, no real likeness. Vertical 1080×1920, 60 fps, Cycles.
Phase 1 only: shots are provisional clips (`shots_provisional.json`, 2750 frames) until the VO arrives.

- `PLAN.md`: shot table, staging, logo, risky shots.
- `review/P1_sheet_1of4.jpg` … `4of4.jpg`: first / middle / last frame of every shot, 540×960, Cycles 8 samples + OIDN.
- `review/BODY_PROP_CROSS.md` (+ json): contact check.
- `scripts/`: the build (no .blend is committed at P1; rebuild takes ~3 min):

```
cd blender/NeverBathed_v001/scripts
./build_all.sh <work_dir> ../assets/models ../shots_provisional.json      # -> <work_dir>/shots.blend
blender -b <work_dir>/shots.blend --python frames.py -- OUT 540 960 8 1,56,110
```

`03_shots.py` is generated by `build_all.sh` from `03_head.py` (helpers adapted from B07), `03_tail_fn.py`,
`03_body.py` (this film's shots) and `03_build.py`.
