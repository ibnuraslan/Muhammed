# EarInArm_v011: farm render sheet

| Item | Value |
|---|---|
| File | `EarInArm_v011_60fps.blend`: compressed, every image packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1572**, step 1 (26.2 s; synced to the voiceover) |
| Camera | One camera, `CAM_Film`. Clean cuts are baked into its keys; no markers. |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy" |
| Output | PNG sequence, written to `//render/EarInArm_v011_####.png` |
| Audio | `EarInArm_v011_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
