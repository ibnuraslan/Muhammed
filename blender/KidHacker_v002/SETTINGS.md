# KidHacker_v002: farm render sheet

| Item | Value |
|---|---|
| File | `KidHacker_v002_60fps.blend`: compressed (21 MB), every image and the VO packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU, 48 samples, adaptive threshold 0.05, OIDN denoise |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–2234**, step 1 (37.2 s; built to the voiceover, last word + 0.5 s) |
| Camera | One camera (`CAM_Film`), clean cuts baked into its keys, no markers |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy" |
| Output | PNG sequence, written to `//render/KidHacker_v002_####.png` |
| Audio | `KidHacker_v002_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
