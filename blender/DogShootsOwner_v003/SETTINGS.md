# DogShootsOwner_v003: farm render sheet

| Item | Value |
|---|---|
| File | `DogShootsOwner_v003_60fps.blend`: compressed, every image and the VO packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU, 48 samples, adaptive threshold 0.05, OpenImageDenoise |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1592**, step 1 (26.5 s; built to the voiceover) |
| Camera | One camera ("Camera"), hard cuts baked into its keys, no markers |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy" |
| Output | PNG sequence, written to `//render/DogShootsOwner_v003_####.png` |
| Audio | `DogShootsOwner_v003_VO.mp3` is packed as a sound strip at frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
