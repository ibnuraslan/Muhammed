# ClosetBathroom_v003: farm render sheet

| Item | Value |
|---|---|
| File | `ClosetBathroom_v003_60fps.blend`: compressed, every image packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU (48 samples, adaptive threshold 0.05, OIDN denoise) |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1881**, step 1 (31.35 s; built to the voiceover) |
| Camera | One camera (`FilmCam`), with the hard cuts baked into its keys and no markers |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy", exposure −0.5 |
| Output | PNG sequence, written to `//render/ClosetBathroom_v003_####.png` |
| Audio | `ClosetBathroom_v003_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
