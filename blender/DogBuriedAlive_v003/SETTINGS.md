# DogBuriedAlive_v003: farm render sheet

| Item | Value |
|---|---|
| File | `DogBuriedAlive_v003_60fps.blend`: compressed (47 MB), every image and the VO packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU; 48 samples, adaptive threshold 0.05, OIDN denoise |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1641**, step 1 (27.35 s; built to the voiceover) |
| Camera | One camera (`CAM_Film`), with the hard cuts baked into its keys and no camera markers |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy", exposure +0.2 |
| Output | PNG sequence, written to `//render/DogBuriedAlive_v003_####.png` |
| Audio | `DogBuriedAlive_v003_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
