# HandlessWarrior_v003: farm render sheet

| Item | Value |
|---|---|
| File | `HandlessWarrior_v003_60fps.blend`: compressed, every image and the VO packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU (48 samples, adaptive 0.05, OIDN) |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1615**, step 1 (26.9 s; built to the voiceover, last word ends at 26.4 s) |
| Cameras | one camera per shot (`CAM_S01`…`CAM_S17`, S04 unused), bound by timeline markers at the VO beat frames: hard cuts |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy" |
| Output | PNG sequence, set the output to `//render/HandlessWarrior_v003_####.png` |
| Audio | `HandlessWarrior_v003_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
