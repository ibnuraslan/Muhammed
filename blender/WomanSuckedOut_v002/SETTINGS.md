# WomanSuckedOut_v002: farm render sheet

| Item | Value |
|---|---|
| File | `WomanSuckedOut_v002_60fps.blend`: compressed, every image and the VO packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU (48 samples, adaptive 0.05, OpenImageDenoise) |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1651**, step 1 (27.5 s; built to the voiceover) |
| Cameras | One camera per shot, bound by timeline markers (hard cuts). 16 markers. |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy". The exterior shots are keyed −0.9 exposure in the file. |
| Output | PNG sequence, written to `//render/WomanSuckedOut_v002_####.png` |
| Audio | `WomanSuckedOut_v002_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
