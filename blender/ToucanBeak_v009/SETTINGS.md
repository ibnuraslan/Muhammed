# ToucanBeak_v009: farm render sheet

| Item | Value |
|---|---|
| File | `ToucanBeak_v009_60fps.blend`: compressed, every image packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1932**, step 1 (32.2 s; built to the voiceover) |
| Camera | One camera, with clean cuts baked into its keys and no markers |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy" |
| Output | PNG sequence, written to `//render/ToucanBeak_v009_####.png` |
| Audio | `ToucanBeak_v009_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
