| Item | Value |
|---|---|
| File | `FridgeTenYears_v003_60fps.blend` (73 MB): compressed, every image and the VO packed |
| Engine | Cycles, CPU or GPU, 48 samples, adaptive threshold 0.05, OIDN denoise |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1651**, step 1 (27.5 s; built to the voiceover, which ends at 27.0 s) |
| Camera | One camera (`CAM_Film`), with the hard cuts baked into its keys and no markers |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy" |
| Output | PNG sequence, written to `//render/FridgeTenYears_v003_####.png` |
| Audio | `FridgeTenYears_v003_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
