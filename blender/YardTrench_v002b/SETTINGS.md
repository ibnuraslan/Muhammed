# YardTrench_v002b: farm render sheet

| Item | Value |
|---|---|
| File | `YardTrench_v002b_60fps.blend`: compressed, every image and the VO packed; opens in factory-startup Blender 5.2.2 with no add-ons |
| Engine | Cycles, CPU or GPU (48 samples, adaptive threshold 0.05, OIDN denoise) |
| Resolution | 1080 × 1920 at 100 % |
| Frame rate | 60 fps |
| Frame range | **1–1825**, step 1 (30.4 s; built to the voiceover, last word ends at frame 1796) |
| Camera | One camera, with clean cuts baked into its keys and no markers |
| Motion blur | Off (the animated look) |
| Colour | AgX, look "Punchy" |
| Output | PNG sequence, written to `//render/YardTrench_v002b_####.png` |
| Audio | `YardTrench_v002b_VO.mp3` is packed as a sound strip from frame 1. Add the mp3 at frame 1 when you encode at 60 fps. |
