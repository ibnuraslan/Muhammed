# B05 Love Canal: shot plan (Phase 1, before the VO)

Film: 1080×1920, 60 fps, Cycles, hard cuts, one camera object (constant-interpolated jump at every cut, smooth move inside a shot).
Client direction (Nov 15): **match the reference sheet** (`briefs/batch2/B05_LoveCanal_reference_1fps.jpg`, 43 s) for shot order,
subjects, framing ideas and pacing. Times below are the reference seconds; Phase 2 moves every cut to the client's VO words.
Every action is animated at 1× from its shot start and runs about 30% past the reference length, so the VO can trim it without stretching.

Cast (generic MPFB characters): **Father** (bald, green shirt), **Boy** (his son, red top), **Mother** (purple), **Neighbour** (long dark hair, cream top),
**Dad2** (neighbour, blue shirt), **Worker** (tan coveralls, yellow hard hat).
