# Al-Jazari: The Father of Robotics

`aljazari.mp4` is a 1920x1080 landscape YouTube video, 1:42 long, in an Islamic-manuscript vintage style.

- **Voiceover:** Kokoro TTS, voice `bm_george`, speed 0.92 (`source/build_vo.py`)
- **Visuals:** drawn in code with HTML canvas (`source/scenes2.js`, `source/props2.js`)
- **Music and sound effects:** made in code (`source/audio2.py`). The music uses the Hijaz scale with oud-style plucks, a frame drum, ney and a drone.

All visuals, music and sound effects were made for this video. Kokoro's licence (Apache 2.0) allows commercial use.
