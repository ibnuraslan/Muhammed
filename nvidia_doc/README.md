# The Spy Allegations Rocking Nvidia: documentary production

This folder holds the documentary to be cut to your voiceover. It runs about 8 to 9 minutes
at 1920×1080 and 24 fps. Every picture is generated by code: 3D scenes are rendered in
Blender Cycles, and the motion graphics are drawn in Python with Skia. The score and the
sound design are synthesized.

## Editorial guardrails (built into the design)

* **No likeness of any real person.** People appear only as empty chairs, as a name in
  type, or not at all.
* **No company or news-outlet logos.** Names appear as plain text in our own typography.
  The office nameplate is a reconstruction in plain letters.
* **Documents are illustrations.** The memo pages contain only redaction bars. The reported
  claim is shown as an attributed pull-quote and never as text inside the memo. Headline
  cards paraphrase the narration and are not mock-ups of real articles.
* **Recreated pictures are labelled on screen.** They carry an `ILLUSTRATION` or
  `RECONSTRUCTION` tag, and every claim carries an on-screen `SOURCE` that matches the
  narration's attribution.
* **On-screen text adds no facts beyond the script.** Dates are shown at the precision the
  script and its sources give.
* **The end card says it outright:** all pictures are illustrations generated in software.

## When the voiceover is ready

```bash
cp /path/to/voiceover.wav vo/voiceover.wav
python edit/align.py vo/voiceover.wav           # beats timed to your words  -> edit/timeline.json
python edit/render_plan.py --script             # frame counts sized to your timing -> out/render_all.sh
PY=/path/to/blender-python out/render_all.sh    # full-quality 3D renders (resumable)
python edit/assemble.py --frames                # composite every frame
python edit/assemble.py --encode                # score + VO mix, encode -> out/the_spy_allegations.mp4
```

Any audio format works, because ffmpeg converts it. The default alignment model is
`small.en`; set `WHISPER_MODEL=medium.en` for an even tighter match. Chapter titles are not
narrated, so the voiceover is automatically opened up at each chapter break to make room
for the cards.

Preview without the final renders:

```bash
python edit/render_plan.py --preview
python edit/assemble.py --storyboard --plates out/plates_preview
```

The first command renders quick low-res plates; the second draws one frame per beat.

## Layout

```
edit/      script.txt, beats.py (beat sheet), align.py, render_plan.py, assemble.py, score.py
mograph/   style.py (design system), canvas.py (Skia), geo.py (Natural Earth maps), templates*.py, preview.py
scenes/    kit.py (materials, instancing, skyline, depth pass), run.py, sc_*.py (one per set)
assets/    fonts (Instrument Serif, Source Serif 4: OFL), geo (Natural Earth 1:50m: public domain), generated/
```

## Requirements

* Python with `bpy==5.2.3`, `numpy`, `scipy`, `pillow`, `skia-python` (needs `libegl1`),
  `pyshp`, and `faster-whisper`
* `ffmpeg`
