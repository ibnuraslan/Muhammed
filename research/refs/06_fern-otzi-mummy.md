## Techniques observed

| Area | What Fern does |
|---|---|
| Structure | Discovery (present) → autopsy (facts) → reconstruction (past, alive) → back to the discovery. Ring structure |
| Hero asset | One photoreal mummy model reused in 30+ shots (macro, wide, top-down) |
| Facts | Stats as kinetic type **inside the 3D room**. Organs as red outlines. "Abstract visualization" disclaimer in a corner |
| VO sync | Each listed body detail gets its own 1 s insert, cut on the spoken word |
| Long takes | The reconstruction uses 43 s, 83 s and 65 s shots on one character |
| Maps | Grey topographic relief maps with a single red route/pin |
| Palette | Cold blue (ice, lab, night) vs warm brown/orange (body, fire). Red only for anatomy and death |
