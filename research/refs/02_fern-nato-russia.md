## Techniques observed

| Area | What Fern does |
|---|---|
| Hook | Headline + map + rapid 3D threat montage (0.6 s shots) → full 3D title sequence → styled disclaimer |
| Spine | Follow one ship, one plane, one train. Every chapter = one obstacle for that asset |
| Maps | A single consistent map system: dark-grey land, teal NATO, red Russia, white pill labels, one ship icon reused. Maps get **long holds (median 9 s, up to 56 s)** |
| Numbers | Icon grids (3.6M vs 1.3M), bar/line charts in the map palette, data point circled, label chips ("37 Days") |
| Hardware | 3D hero shot with name label → 2D blueprint with specs |
| 3D look | Desaturated grey daylight. Objects on black voids with a hard top light. Only red is saturated (train, servers, fire) |
| Characters | Few: a commander, a captain, saboteurs. Faces get an ECU only at decision moments. Saboteurs are hooded = no face needed |
| Live | The interview is lit on black with a ring light, so it matches the 3D void look |
